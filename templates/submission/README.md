# Public task submission templates

Start with these shared templates:

- [Task plan (Markdown)](task-plan.md)
- [Reference rankings and column guide (Excel)](reference-rankings.xlsx)
- [Both templates as a ZIP](submission-template.zip)

Replace placeholders and describe the scientific objective, candidate groups, experimental conditions, model-visible inputs, evidence, ranking rules, and every data column. The workbook includes fictional examples for orientation; replace them with the submitted task’s own authorized data.

For a public PR, put the completed files in `submissions/<task-id>/` or place a single `submission.zip` there. Do not mix the ZIP with loose submission files. See [CONTRIBUTING.md](../../CONTRIBUTING.md) and the [fictional walkthrough](../../examples/public-intake/README.md).

Public PR contents, including reference answers, must be permitted for redistribution. Submit private experiments through the private workspace on the [SPU project site](https://spu.unipat.ai/#/workspace) instead.
